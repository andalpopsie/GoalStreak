## 📋 What Each File Tracks

progress-tracker.md
• Overall project progress by phase
• Completion percentages and milestones
• Current sprint focus and weekly goals
• Key deliverables and deadlines

decisions-log.md
• All technical and design decisions with rationale
• Architecture choices (React Native, Firebase, etc.)
• Feature scope decisions
• Future decisions that need to be made

issues-blockers.md
• Current blockers that stop progress
• Open issues that need resolution
• Risk mitigation strategies
• Issue templates and escalation process

next-actions.md
• Immediate next steps for current session
• Weekly action plans
• Preparation checklists
• Success criteria and time estimates

session-logs/session-001-2025-08-20.md
• Detailed log of today's session
• Tasks completed and decisions made
• Time tracking and productivity metrics
• Action items for next session
