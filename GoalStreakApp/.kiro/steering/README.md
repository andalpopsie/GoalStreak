# Steering Documents

These documents guide AI development for GoalStreak. They are automatically included in AI context.

## Active Steering Rules

### `development-workflow.md`
**Purpose**: Core development practices for file changes, commits, and verification
**When Applied**: Always (for all AI interactions)
**Key Rules**:
- Verify every file change with `git diff`
- Commit important changes immediately
- Add verification logs
- Clear cache properly

### `spacing-standards.md`
**Purpose**: Mobile spacing and layout standards for consistent UI
**When Applied**: Always (for all UI/component development)
**Key Rules**:
- Use 4px base grid → 8, 16, 24, 32
- Follow card layout recipe (16px margins, 16-24px padding)
- Minimum 48px touch targets
- Consistent spacing hierarchy

## How Steering Works

Steering documents are automatically included in AI context to ensure consistent development practices. Keep them:
- **Concise**: Focus on actionable rules
- **Clear**: Specific instructions, not general advice
- **Current**: Update when practices change
