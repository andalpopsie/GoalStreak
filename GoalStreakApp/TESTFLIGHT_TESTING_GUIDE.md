# GoalStreak TestFlight Testing Guide

Thank you for testing GoalStreak! Your feedback is crucial for making this app amazing.

## 🎯 What to Test

### 1. First-Time Experience (5 min)
- [ ] Download and open the app
- [ ] Go through the onboarding carousel
- [ ] Create your account (email/password or Google)
- [ ] Set up notification preferences
- [ ] **Feedback:** Was onboarding clear and engaging?

### 2. Creating Habits (10 min)
- [ ] Create 3-5 different habits with various categories
- [ ] Try different frequencies (daily, weekly, custom)
- [ ] Add habits with and without target values
- [ ] Test the timer feature on a habit
- [ ] **Feedback:** Is habit creation intuitive? Any confusing parts?

### 3. Daily Usage Flow (15 min)
- [ ] Mark habits as complete for today
- [ ] Try completing the same habit twice (should prevent)
- [ ] Undo a completion
- [ ] Complete habits at different times (morning, evening)
- [ ] Check your streak counter
- [ ] **Feedback:** Does the completion flow feel satisfying?

### 4. Analytics & Progress (10 min)
- [ ] View your Analytics screen
- [ ] Check completion rate and streak stats
- [ ] Look at the calendar view
- [ ] Review weekly/monthly patterns
- [ ] **Feedback:** Are the stats helpful and easy to understand?

### 5. Social Features (15 min)
- [ ] Go to Social tab
- [ ] Add a friend by email (coordinate with another tester)
- [ ] View friend suggestions
- [ ] React to friend activities (❤️ 🔥 🏅)
- [ ] Leave comments on activities
- [ ] Check your activity feed
- [ ] **Feedback:** Is the social aspect motivating? Any privacy concerns?

### 6. Achievements (10 min)
- [ ] Check Profile screen for badges
- [ ] Complete actions to unlock achievements:
  - Complete your first habit (First Step)
  - Build a 3-day streak (First Flame)
  - Add a friend (Social Butterfly)
  - React to activities (Cheerleader)
  - Leave comments (Conversation Starter)
- [ ] **Feedback:** Are achievements motivating? Want more?

### 7. Notifications (Test over 2-3 days)
- [ ] Enable habit reminders
- [ ] Set reminder times
- [ ] Wait for daily motivation notification (if enabled)
- [ ] Check if you get inactivity nudges after being inactive
- [ ] Test friend request/comment notifications
- [ ] **Feedback:** Are notifications helpful or annoying?

### 8. Profile & Settings (5 min)
- [ ] Upload a profile photo
- [ ] Edit your display name
- [ ] Adjust notification settings
- [ ] Toggle social notification preferences
- [ ] Sign out and sign back in
- [ ] **Feedback:** Any settings you wish existed?

### 9. Edge Cases & Bugs (Ongoing)
- [ ] Force close the app and reopen
- [ ] Switch between tabs quickly
- [ ] Try with poor internet connection
- [ ] Use the app across multiple days
- [ ] Test on different iOS versions if possible
- [ ] **Feedback:** Any crashes, freezes, or weird behavior?

## 🐛 How to Report Issues

### Critical Bugs (App crashes, data loss)
**Report immediately with:**
- What you were doing when it happened
- Your device model and iOS version
- Screenshots if possible

### Minor Issues (UI glitches, typos)
**Note and report with:**
- Where you saw it
- Screenshot
- Suggested fix (optional)

### Feature Requests
**Share your ideas:**
- What feature would make the app better?
- Why would it help you?
- How would you use it?

## 💡 Key Questions for Feedback

1. **First Impression:** What was your first reaction to the app?
2. **Daily Use:** Would you use this app every day? Why or why not?
3. **Motivation:** Does the app make you want to stick to your habits?
4. **Social:** Do you like the social features or prefer solo tracking?
5. **Design:** Is the app visually appealing? Any design issues?
6. **Performance:** Does the app feel fast and responsive?
7. **Missing Features:** What's the ONE feature you wish it had?
8. **Comparison:** How does it compare to other habit apps you've tried?
9. **Pricing:** Would you pay for this app? How much?
10. **Recommendation:** Would you recommend this to a friend?

## 📊 Specific Metrics to Track

- **Time to first habit created:** How long from download to first habit?
- **Daily return rate:** Do you open the app daily?
- **Completion rate:** What % of your habits do you complete?
- **Social engagement:** Do you interact with friends?
- **Achievement unlocks:** How many badges did you earn?
