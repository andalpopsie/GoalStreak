# Screenshot Generation Guide

## Required Screenshots for App Store

### iPhone Screenshots (Required)
1. **iPhone 6.7"** (iPhone 15 Pro Max) - 1290 x 2796 pixels
2. **iPhone 6.5"** (iPhone 14 Plus) - 1242 x 2688 pixels
3. **iPhone 5.5"** (iPhone 8 Plus) - 1242 x 2208 pixels

### iPad Screenshots (If supporting iPad)
1. **iPad Pro 12.9"** (6th gen) - 2048 x 2732 pixels
2. **iPad Pro 12.9"** (2nd gen) - 2048 x 2732 pixels

## How to Generate Screenshots

### Method 1: iOS Simulator
1. Open iOS Simulator
2. Choose iPhone 15 Pro Max
3. Run your app: `npm start` then press `i`
4. Navigate to each screen
5. Take screenshots: `Cmd + S`
6. Screenshots saved to Desktop

### Method 2: Physical Device
1. Run app on iPhone
2. Navigate to each screen
3. Take screenshots: Volume Up + Side Button
4. AirDrop or sync to Mac

### Method 3: Expo Development Build
1. Create development build
2. Install on device
3. Take screenshots directly

## Screenshot Enhancement Tips

### Add Marketing Text Overlays
- Use tools like Figma, Canva, or Sketch
- Add compelling titles and descriptions
- Use your brand colors (#4ECDC4)
- Keep text readable and not overwhelming

### Consistent Styling
- Same device frame for all screenshots
- Consistent background colors
- Same time/battery indicators
- Professional appearance

### Content Guidelines
- Show real, meaningful data (not Lorem Ipsum)
- Demonstrate key features clearly
- Use appealing color combinations
- Ensure text is legible at small sizes
