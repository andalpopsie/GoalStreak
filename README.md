# 🎯 GoalStreak - Social Habit Tracking Platform

> **Status**: Production Ready ✅ | **MVP**: 100% Complete | **App Store**: Ready for Submission

A modern social habit tracking app built with React Native, Expo, and Firebase. Transform your habits into lasting change with friends, timers, and powerful analytics.

## 🚀 Quick Start

```bash
# Clone and setup
git clone https://github.com/andalpopsie/GoalStreak.git
cd GoalStreak/GoalStreakApp

# Install dependencies
npm install

# Start development
npm start
```

## ✨ Features

### 🎯 Core Habit Tracking
- **Smart Habit Creation** - 39+ category icons with intelligent suggestions
- **Streak Tracking** - Visual progress with milestone celebrations
- **Flexible Scheduling** - Daily, weekly, monthly habit frequencies
- **Offline Support** - Works without internet, syncs when online

### 👥 Social Accountability
- **Friend System** - Connect with friends for mutual motivation
- **Activity Feed** - Real-time updates of friends' progress
- **Reactions** - Heart, flame, and medal reactions for encouragement
- **Privacy Controls** - Granular sharing settings

### ⏱️ Productivity Tools
- **Pomodoro Timers** - Built-in focus timers with auto-completion
- **Progress Visualization** - Animated circular progress indicators
- **Analytics Dashboard** - Comprehensive insights and trends

### 🔔 Smart Notifications
- **Intelligent Scheduling** - 7-day advance notification system
- **Timezone Aware** - Automatic device timezone handling
- **Modern UI** - Scrollable time pickers and intuitive controls

## 🏗️ Technical Stack

- **Frontend**: React Native + Expo SDK 54
- **Backend**: Firebase (Auth, Firestore, Storage, FCM)
- **Language**: TypeScript (100% coverage)
- **Navigation**: React Navigation 7.x
- **Animations**: React Native Reanimated 3.x
- **State Management**: React Context + Custom Hooks
