# GoalStreak Screenshot Planning Guide

## Required Sizes

### iPhone Screenshots
- **6.7" (iPhone 14 Pro Max):** 1290 x 2796 pixels
- **6.5" (iPhone 11 Pro Max):** 1242 x 2688 pixels  
- **5.5" (iPhone 8 Plus):** 1242 x 2208 pixels

### iPad Screenshots
- **12.9" (iPad Pro):** 2048 x 2732 pixels
- **11" (iPad Pro):** 1668 x 2388 pixels

## Screenshot Sequence (5 screenshots max)

### Screenshot 1: Home Dashboard
**Focus:** Beautiful habit cards with category icons
- Show 4-6 habit cards with different categories
- Mix of completed/incomplete states
- Display streak numbers
- Show the elegant completion checkmarks

### Screenshot 2: Social Feed
**Focus:** Friends and community features
- Friend activity feed with recent completions
- Show friend achievements and milestones
- Display social sharing features
- Highlight community motivation

### Screenshot 3: Analytics Dashboard
**Focus:** Beautiful progress insights
- Show progress chart with trend line
- Display key stats (completion rate, streaks)
- Show personal insights cards
- Highlight data visualization

### Screenshot 4: Habit Creation
**Focus:** Easy setup with beautiful icons
- Show category selection with 25+ icons
- Display habit templates (Workout, Yoga, Water, etc.)
- Show the clean, intuitive creation flow
- Highlight customization options

### Screenshot 5: Profile & Settings
**Focus:** Personalization and control
- Show user profile with achievements
- Display theme/customization options
- Show notification settings
- Highlight privacy controls

## Screenshot Tips

### Design Elements
- Use light mode for better App Store visibility
- Show realistic but impressive data (7-day streaks, etc.)
- Include diverse habit categories
- Show active, engaging states

### Text Overlays (Optional)
- "Build lasting habits" (Screenshot 1)
- "Stay motivated together" (Screenshot 2)  
- "Track your progress" (Screenshot 3)
- "25+ beautiful categories" (Screenshot 4)
- "Your habits, your way" (Screenshot 5)

## Tools Needed
- iOS Simulator (for perfect screenshots)
- Screenshot editing app (for overlays/annotations)
- Device frames (optional, for marketing)

## Checklist Before Submission
- [ ] All 5 screenshots captured in highest resolution
- [ ] Screenshots show diverse, realistic usage
- [ ] No personal/sensitive information visible
- [ ] All UI elements properly displayed
- [ ] Screenshots highlight key app benefits
- [ ] Consistent visual style across all screenshots
