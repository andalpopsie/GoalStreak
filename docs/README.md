## 📝 Documentation standards

- **Modify, don't multiply** — extend an existing doc rather than adding a near-duplicate.
- **Keep it accurate** — remove or update stale references promptly (this index links only to files that exist).
- **Cross-link** — point to the canonical location instead of copying content.
