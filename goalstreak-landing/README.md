# GoalStreak Landing Page

A modern, responsive landing page for the GoalStreak habit tracking app.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Project Structure

```
goalstreak-landing/
├── src/
│   └── app/
│       ├── layout.tsx      # Root layout
│       ├── page.tsx        # Home page
│       └── globals.css     # Global styles
├── package.json
├── next.config.js
└── tsconfig.json
```

## Features

- ✅ **Modern Design**: Clean, gradient-based design with smooth animations
- ✅ **Responsive**: Works perfectly on desktop, tablet, and mobile
- ✅ **Fast Loading**: Optimized with Next.js for performance
- ✅ **SEO Ready**: Proper meta tags and structure
- ✅ **TypeScript**: Full type safety

## Sections

1. **Hero Section**: Eye-catching intro with call-to-action
2. **Features Grid**: 6 key features with icons and descriptions
3. **Download Section**: App store links and download buttons
4. **Footer**: Simple footer with copyright

## Customization

- Edit `src/app/page.tsx` for content changes
- Modify `src/app/globals.css` for styling updates
- Update `src/app/layout.tsx` for SEO metadata

## Deployment

Ready for deployment to:
- Vercel (recommended for Next.js)
- Netlify
- Any static hosting service

The landing page showcases your GoalStreak app's key features and provides download links for users.
