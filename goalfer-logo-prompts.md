## Tips when generating

- Generate 8–12 variations per prompt. You're looking for the one with *perfect* geometry, not interesting detail.
- If the output has too much detail or texture, add: `flat, vector, no texture, no noise`.
- If it adds letters or words, add: `no text, no letters, no typography`.
- For Ideogram specifically, add "logo on plain white background" — Ideogram follows that instruction more literally.
- Always ask for a square (`--ar 1:1`). App icons are square.

## After you pick a direction

1. Import the AI render into Figma as a reference only.
2. Rebuild the shape with Figma's pen + circle tools so the geometry is mathematically clean (AI-generated logos always look "almost right" — the redraw is what makes it ship-quality).
3. Lock proportions on a 24×24 grid.
4. Export at 1024×1024 for the App Store, and as SVG for everything else.
